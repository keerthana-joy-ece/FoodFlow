# FoodFlow – Food Delivery Mobile Application

## Project Overview
FoodFlow is a food delivery mobile application developed using React Native and Expo. It provides users with a convenient way to browse food items, add products to their cart, place orders, and track deliveries.

## Technologies Used
- React Native
- Expo
- JavaScript
- Firebase Authentication
- AsyncStorage (if configured in the project)

## Main Features
- Splash screen and onboarding
- User login and signup
- Home screen with food categories
- Food details and product selection
- Shopping cart
- Checkout and payment screens
- Order confirmation
- My Orders and order tracking
- User profile and settings

## Project Structure
- `App.js` – Main application entry point
- `src/components/` – Reusable UI components
- `src/screens/` – Application screens
- `src/constants/` – App constants and colors
- `src/firebase/` – Firebase configuration
- `assets/` – Images and application assets

## Running the Project Locally

1. Clone the repository:
   `git clone https://github.com/keerthana-joy-ece/FoodFlow.git`

2. Open the project folder:
   `cd FoodFlow`

3. Install dependencies:
   `npm install`

4. Start Expo:
   `npx expo start`

## Android Build
The Android APK was generated using Expo Application Services (EAS Build).
